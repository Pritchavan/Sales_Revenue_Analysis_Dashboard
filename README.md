# 📊 Sales & Revenue Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Sales & Revenue Analysis Dashboard** developed in **Microsoft Excel**. It helps analyze sales performance, revenue trends, product performance, and regional sales using Pivot Tables, Pivot Charts, KPIs, and Slicers.

---

## 🎯 Objectives

- Analyze overall sales performance
- Monitor revenue and order trends
- Identify top-performing products
- Compare revenue across different regions and categories
- Build an interactive dashboard for business insights

---

## 📈 Dashboard Features

- 💰 Total Revenue KPI
- 🛒 Total Orders KPI
- 📦 Total Units Sold KPI
- 💵 Average Order Value KPI
- 📊 Revenue by Category
- 🌍 Revenue by Region
- 📈 Monthly Revenue Trend
- 🏆 Top 5 Products by Revenue
- 🎛 Interactive Slicers (Year, Month, Region & Category)

---

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- GETPIVOTDATA Formula
- Conditional Formatting
- Number Formatting

---

## 📂 Dataset

The dataset contains sales transaction records with the following fields:

- Order ID
- Order Date
- Product
- Category
- Region
- Sales Representative
- Units Sold
- Unit Price
- Revenue
- Month
- Year
